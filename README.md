## 📌 Featured Repositories

### ⭐ [4mulaQuery — Custom Database Engine](https://github.com/4mulaMind-Org/4mulaQuery)
Fully functional relational database engine built from scratch in **C++** — no existing DB library used. **B+ Tree indexing** for O(log n) operations, binary file storage, **Java Spring Boot REST API** bridge, and **ML anomaly-detection pipeline** (Python Isolation Forest) for slow-query detection. Dockerized and deployed live[reference:12].

### ⭐ [Provider Matrix — Distributed Lead Allocation](https://github.com/4mulaMind-Org/ProviderMatrix)
Production-grade distributed lead allocation platform simulating real marketplace infrastructure under high concurrency. **ACID-compliant transactions** with PostgreSQL row-level locking (`FOR UPDATE`), deterministic fair round-robin allocation, **idempotent webhook processing**, and real-time WebSocket monitoring[reference:13].

### ⭐ [GitFlow — Smart Leads Dashboard](https://github.com/4mulaMind-Org/AssignmentServiceHive)
Full-stack lead management workspace with **JWT auth + Bcrypt**, compound filtering engine (Status + Source + full-text search), backend pagination via **MongoDB aggregation pipelines**, **RBAC** for Admin/Sales, CSV export, and multi-container **Docker Compose** with strict TypeScript[reference:14].

### ⭐ [Developer Productivity MVP](https://github.com/4mulaMind-Org/mvp)
Productivity analytics platform computing all **5 DORA metrics** via MongoDB aggregations (Cycle Time, Lead Time, Bug Rate, Deployment Frequency, PR Throughput). Includes a **rule-based insight engine** mapping metric patterns to root-cause diagnoses with separate IC and Manager dashboards[reference:15].

### 🏥 [Hospital Management System](https://github.com/qadir4mulaMind)
Full-stack dashboard for registering and managing patients, doctors, and appointments. **RESTful API with 15+ endpoints** (Node.js, zero external deps), full CRUD with JSON-file persistence, real-time search/filtering, one-click CSV export, and an integrated **AI chatbot assistant** for doctor search and appointment booking[reference:16].

### 🌦️ [Weather Forecast App](https://github.com/qadir4mulaMind)
RESTful weather backend in **Java Spring Boot** with clean layered architecture (Controller, Service, DTO). External API responses modeled into dedicated DTOs for a stable API contract. Separate **HTML/CSS/JS frontend** consuming the backend to display live temperature, humidity, wind, sunrise/sunset, and forecasts[reference:17].

### 🤖 [Contest Reminder — PWA](https://github.com/qadir4mulaMind/-Contest-Reminder)
Progressive Web App that aggregates upcoming DSA contests from **8+ platforms** — Codeforces, LeetCode, CodeChef, AtCoder, HackerRank, HackerEarth, TopCoder, and Toph — in one place. **FastAPI backend**, IST timezone, live status, offline support, dark mode, and auto-refresh every 5 minutes[reference:18].
